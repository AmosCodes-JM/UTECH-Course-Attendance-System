## Notes and differences from the guide

- **npm 11 install-script approvals.** npm 11 blocks dependency install scripts until approved. Prisma's (`prisma`, `@prisma/engines`) were approved and recorded in `server/package.json` → `allowScripts`; bcrypt's source rebuild was denied because bcrypt 6 ships working prebuilt binaries.
- **Prisma 7 client is TypeScript.** The `prisma-client` generator writes `.ts` files; Node 24's built-in type stripping imports them directly, so the server stays plain JavaScript with no build step (`import { PrismaClient } from '../generated/prisma/client.ts'`).
- **Prisma config file.** The guide shows `prisma.config.ts`; this project uses the equivalent `server/prisma.config.js`, with the schema and migrations under `server/src/db/` as the build instructions require.
- **Timezone.** The machine's timezone is `America/Bogota` (UTC-5). Database connections are pinned to UTC (see [DATABASE-GUIDE.md](DATABASE-GUIDE.md#timezones)); display and date filters use `APP_TIMEZONE=America/Jamaica`.
- **Shell note.** Non-interactive shells don't read `~/.bashrc`, so scripts that need Node should load NVM first: `export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"`.
